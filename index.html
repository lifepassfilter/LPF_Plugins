    Install help

    Builds are not code-signed yet, so your OS may complain the first time.

    macOS says the plugin “is damaged” or “can't be opened”

    Some plugins ship an installer that handles this for you. Otherwise, copy the .vst3 / .component to your plugin folder, then run this in Terminal (adjust the name):

    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"LPF Facet.vst3"
    Windows shows “Windows protected your PC”

    Click “More info”, then “Run anyway”. Plugins go to C:\Program Files\Common Files\VST3.

    Where do I report a bug or ask for a feature?

    Each plugin has a “Source” link: open an issue on its GitHub page.
